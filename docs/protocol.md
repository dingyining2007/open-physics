# 三条规则

这个小仓库只做一件事：**把「我觉得」变成「你也能跑出来」。**

---

## 规则 1 · 每个数字必须可复算

不合格：

> Running vacuum 模型的 ν 与 QFT 预期差很多。

合格：

> RVM 论文 arXiv:2608.23633 式 (3) 给 `ν = (1/6π)Σ B_i M_i²/M_P²`。
> 取最重已知粒子 m_t = 173 GeV、未约化 M_P = 1.220890×10²⁸ eV：
> `ν_QFT = (1/6π)(173×10⁹/1.220890×10²⁸)² = 1.065×10⁻³⁵`
> 论文 Table 4 Model B 拟合值 ν = 0.109 ± 0.020。
> 差 1.0×10³⁴ 倍。脚本见 `scripts/rv_recompute.py` 第 ① 节。

**任何数值必须附三样：来源标识（DOI/arXiv/文件名+行号）、口径（单位、置信水平、中心值还是后验）、可运行代码。**

---

## 规则 2 · 三级依据标签

| 标签 | 判据 | 可否进结论栏 |
|---|---|---|
| `【实测】` | 有 HTTP 200 的页面 / PDF 原文某行 | ✅ |
| `【复算】` | 本机脚本可复现 | ✅ |
| `【推断】` | 仅据命名、文档、二手转述 | ❌ 只能当假设 |

**外部 AI、专家、任何人的结论，若未附可核查证据，一律自动降级为【推断】。**

这条规则救过我一次：某个高能力模型断言「arXiv:2608.23633 是虚构编号」。
我三源核查（abs 页 / HTML 全文 / Semantic Scholar 反查）后确认文献真实。
**如果按它说的做，我会删掉一份真实文献。**

---

## 规则 3 · 分歧要定位到参数，不要表决

两个模型给出相反答案时，**不要数票**。

**正确做法**：去找「哪个参数的哪个取值能解释这个分歧」。

> **实例**：某模型说「2.2403 meV 不可能是标准 QCD 轴子」，另两个说「可以」。
> 复算 `g_agg = α_s/(2π f_a)·|E/N − 1.92|` 后发现：
> **当 E/N = 1.92 时此式精确为 0**。
> ⇒ 分歧点精确定位在 E/N 这一个参数的取值上。
> ⇒ 应标「**悬置**」，而不是「2:1 多数通过」。

**为什么不能表决**：多数票会把「参数没对上」误读成「物理结论」。

## 附加规则 · 自己的错要写进正文

不是附录，不是脚注，是正文。

因为我们验证方法论的方式只有一种：**看它在自己犯错时能不能抓住。**

本仓库公开记录了 6 处我自己的计算错误，见 [README](../README.md#我在这个过程中犯的错公开记录)。
其中有 1 处（BBN 判据错 9 个数量级）直接推翻了一个已经写进文档的结论。

**如果不公开，下一个读文档的人会继承这个错。**
