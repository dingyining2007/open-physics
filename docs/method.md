# docs/method.md — 核验方法

**版本**：2026-11-25（新增杀招〇、杀招二·补、第八·补节）
**适用**：任何"有人提出一套理论，声称能解释某个物理现象"的场合。
**不适用**：直接评价人、评价动机、评价商业行为。**本文只谈数学结构与可检验性。**

---

## 〇、一句话判据

> **不是"我的理论能解释一切"，而是"我的理论对 X 给出 Y=Z，而 X 已经有实验值"。**
> **交出一个数，且与某个已测量可比。**

三条推论：

1. **"能解释"不算成果，"算出数"才算。** 任何理论都能解释任何现象——这正是"能解释"没有价值的原因。
2. **阴性结果同样有价值。** 算出"这条路不通"并说清为什么不通，等于排除了一条路。只有"既不给出数、也不宣布排除"才是最没价值的。
3. **自由参数必须由理论定，不能由数据定。** 一个能调到对上任何数的参数，等于没有预言。

## 一、第一步：拆线（不做这一步，后面全串账）

同一个名字下常并着好几件东西。先拆开、分别记账：

| 类型 | 例子（2026-11-24 实案） |
|---|---|
| **A. 一本正式书** | 《空间相对论》，苏恩杰+房文祥合著，有 ISBN，**正文未取到** |
| **B. 另一本有公式的书** | 《真空动态理论的数学原理》，方远洋主编、房文祥副主编 |
| **C. 个人 IP 的知识库** | "太易生/房子老师"文字，无公式，定性叙述 |
| **D. 并列出现的第三个体系** | 张祥前统一场论，被 C 站台 |

**拆线三条纪律**：

1. **异写也是同一人**（"房文详"→"房文祥"），不要把一个人记成两个人；
2. **同一个人参与 ≠ 同一本书**，不要把 B 的公式账算到 A 头上；
3. **个人诠释 ≠ 正式著作内容**——C 里的意识/扬升内容一旦被当作 A 的内容，A 就永远进不了学术讨论。**这个区分对对方是保护，不是攻击。**

## 二、第二步：材料状态先声明，再判断

| 状态 | 允许说什么 |
|---|---|
| **正文取到并通读** | 可以判断对错 |
| **只取到摘要/摘录** | 只能说"摘录如此" |
| **正文未取到** | **只能说"未提交"，不能说"错"** |

> **没有正文，就没有资格说它错。**

**实案**：A 线《空间相对论》Amazon 反爬、网盘只有 172MB 推介 PPT 未解析 ⇒ 对 A 线全部判断标
「未提交」。**这个边界一次都没越过。**

**反例（同一天的真实教训）**：格点论文 arXiv:2608.22587 的 PDF 用三条通道下载三次，
每次尾部都被截断（`%%EOF` 缺失，字节数各不相同）。

- **错误做法**：据此说"论文有问题"；
- **正确做法**：判定**传输层截断**，换 arXiv HTML 全文（301,757 字节完整），
  在正文 Eq.(1) 里取到了原定义。**问题在我的输入，不在对方。**

## 三、第三步：把"概念像"与"数学是"分开

**概念接近 ≠ 数学等价。**

要把"像"变成"是"，必须做到两件事之一：

| 路径 | 要交什么 | 判据 |
|---|---|---|
| **作用量对照** | 我的每个概念 → 对方作用量中哪一项 → 缺哪一项 | 一张表填完，"是不是同一个理论"自己就有答案 |
| **场方程一致** | 写出自己的应力-能量张量，与对方场方程逐项比 | 逐项对得上才算 |

**实案（SQS 路线）**：把真空当超流介质、粒子当涡旋、引力当压力梯度——国际上已走了十几年
（HAL `hal-01248015v6`）。**这不是坏事**：有现成数学可直接对接，十年可省。
**但要证明"在路上"，不能自称。证明方式只有逐项对照。**

## 四、第四步：预注册判据（先声明，再算）

```
【预注册】目标量 X：____（必须已有实验值 W=____，写明来源）
【模型内推导】我的理论对 X 给出 Y = ____（写出推导，不用"可以解释"）
【判据】|Y−W|/W < ____ 则支持；> ____ 则排除；c=0 或参数由 X 反拟合则不算
【执行】先冻结上面三行，再代入计算
【结论】支持 / 排除 / 未提交——三选一，附数值
```

**选量的三条原则**：

1. **已精确测量**（电子反常磁矩 `a_e`、兰姆位移、氢 10.2 eV、星系旋转曲线）；
2. **在对方模型内部可算**（不是"原则上能解释"）；
3. **自由参数已被其他约束定死**（否则可拟合任何数，等于没预言）。

> **先声明目标是关键。** 这样阴性结果也有价值（排除一条路＝B 档），不是白干。

## 五、第五步：四条常用杀招

### 杀招〇：范畴错误（比数据缺口更重，2026-11-25 新增）

**症状**：一套规则被宣称**在所有尺度通用**：恒星坍缩、地质灾变、物种灭绝、文明崩塌、生命衰老，都由同一规则触发。

**第一步：先把「通用」拆成一张量纲表。** 每个尺度一行，逐行问三个问题：

| 尺度 | 真实的临界判据 | 量纲 | 有无 O(1) 无量纲判据 |
|---|---|---|---|
| 恒星坍缩 | 钱德拉塞卡极限 | [M] | ✅ **有** |
| 星系合并 | 无公认临界 | 时间 / 率 | ❌ |
| 地质灾变 | 断层应力 vs 摩擦强度 | [Pa] | ❌ |
| 物种灭绝 | 化石记录幂律 | 计数 | ❌ 指数有争议 |
| 文明崩塌 | 收益递减 | 比例 | ❌（有可算模型，无公认临界值） |
| 生命衰老 | 死亡率随龄上升 | [1/T] | ❌ |

**第二步：找那一行数学结构真不一样的。** 最硬的一行是衰老：

| | 表达式 | 临界点行为 |
|---|---|---|
| 相变（Ising） | `Ψ ~ abs(t)^β` | `t=0` 处**非解析**，导数发散 |
| 衰老（Gompertz） | `μ(a) = A·e^{Ba}` | **处处解析，无奇点** |

**一个非解析、一个处处平滑 ⇒ 这是两种不同的数学对象，不是同一个对象的两个例子。**

> **⇒「所有尺度通用」不是「还没给出」，是「给不出」——那六件不是同一类现象。**
>
> **这叫范畴错误，不叫数据缺口。数据缺口会随时间补上，范畴错误不会。**

**为什么它比数据缺口更该优先指出**：判它不需要任何数值输入，只需要看量纲。**成本最低、结论最硬。**

**⟹ 但它不能反过来说「这套体系没价值」。** 正确做法是把它降成可兑现的形式：
「X 是**同一类结构的统一命名，具体判据逐尺度给出**」——填一格是一格进展，不会因为一格填不出就全盘判死。

### 杀招一：恒等式冒充证明

**症状**：一个"验证"只用到定义本身，不含任何外部信息。

**实案**：我曾用 `m_P ≡ √(ħc/G)` 的定义恒等式去"验证"某个数值关系——
这不是验证，是把定义抄了一遍。**这是我在 2026-11-24 之前认下的最重一笔错。**

**检验法**：把公式里所有符号换成定义，看两边是否恒等。**恒等 ⇒ 零信息量。**

### 杀招二：一个数被拆成"缺口"

**症状**：两个偏差看起来是两次独立的算错，其实来自同一个代数必然。

**实案**：某体系给电子、质子两个振动频率，代进它的公式分别差 9394 倍与 51282 倍。
看起来是两次错误。**但**：

```
r = ke²/(mc²)                                  ← 经典半径
ħ/(2mr²) ÷ (mc²/ħ) = ħ²c²/(2k²e⁴) = 1/(2α²) ≈ 9389.4    ← 质量完全约掉
```

⇒ 对一个**与质量无关**的恒等式，"两个粒子都差 9394 倍"就不再是两次巧合，
而是同一个代数的必然结果。

**进一步**：两偏差之比 5.4616 = `ω_C,p/ω_p`，即"给定质子频率相对康普顿频率的缺口"。
**缺口不是一个常数，是需要由方程填上的位置。**

**检验法**：试至少三种已知常数组合；若都不中，问对方**"这个数可由你的方程唯一确定吗？"**

### 杀招二·补：判据必须不能被措辞消解（2026-11-25 新增）

**症状**：你的批评在措辞上无懈可击，但对方一句话就能接住。

**实案**：我批评某体系的双向循环「若双向可逆，须给逆映射——文档给了 0 个」。
**对方只需回一句「逆映射就是时间反演」**，这句话我无法反驳。
⇒ **这条批评属无限定强断言，被自己的规则打掉。**

**换成熵账，就挡不住了**：

> 恒星坍缩（引力势能→中微子与辐射）：**熵增**
> 生命衰老：**熵增**
> 物种灭绝：**熵增**
>
> 而该文档明写「全域闭环」，且终态要抹平一切差值。
> **⇒ 被抹掉的熵去哪了？**
> 要么给一个熵汇（说明系统其实不闭合，有外部环境），要么承认循环**不是闭合的**——与「全域闭环」直接矛盾。

**热力学第二定律不是措辞问题，所以这条挡得住。**

**检验法（写批评前先自己跑一遍）**：
1. 把判据写成一句话；
2. 想一个最省力的化解话术；
3. **如果化解成功 ⇒ 判据选错了，换一个。**

### 杀招三：把"必然结果"当"特征预言"

**症状**：理论给出一项性质，但该性质是**任何此类模型都有的**。

**实案**：某体系说"物质是空间的环形驻波，故给出离散谱"。
但**有限腔＋驻波必然给离散谱**——这与"水是湿的"同类，不构成理论特征。

**升级为可判**：比谱形。

| 结构 | 谱 | 定标 |
|---|---|---|
| 环上自由粒子（固定半径 R） | `E_n = n²ħ²/(2mR²)` | `∝n²`，间距递增 |
| 环 + 环心点电荷 | `−ke²/R` 是常数势，只整体平移 | **仍 ∝n²** |
| 氢原子（可变径向） | `−13.6 eV/n²` | `∝−1/n²`，间距递减 |

**关键几何事实**：环上每一点到环心的距离**恒为 R**，所以中心点电荷给的是**常数势**，
变不出 `−1/n²`。**这是几何必然，可当场验算。**

⇒ 问题收敛为二选一：**(a) 固定半径环 → 谱形方向相反，当场否；(b) 含可变径向 → 那已是标准库仑模型，环形特征消失。**

## 五·补、解释 还是 改名？——额外输入能否被独立测量

**这是 2026-11-24 结 Q4 时确立的判据，也是本方法最实用的一条。**

很多"解决方案"都给问题加了一个新东西：一个新对称、一个新粒子、一个新能标、一个新整数。
**加了东西不等于解释了问题。** 判别标准只有一条：

> **它引入的那个额外输入，能不能被别的实验独立测出来？**

| 能测 | = **解释**（有独立生死线，可被单独杀死） |
|---|---|
| 不能测 | = **改名**（把"为什么小"换成了"为什么这个参数取这个值"，问题平移了一步） |

**实案（strong CP，2026-11-24）**：

| 方案 | 额外输入 | 该输入可否独立测量 | 判定 |
|---|---|---|---|
| PQ 轴子 | 新全局对称 + 破缺能标 f_a | 能（轴子耦合；ADMX / SN1987A 冷却）| **解释** |
| Nelson-Barr | 新粒子 + 质量矩阵强制实 | 能（CKM 的 CP 相位偏差，B 介子精确测量）| **解释** |
| 高能 CP 完全守恒 | 一个新假设 + 破缺机制 | 部分（须先说明破缺发生在哪个能标）| **改名** |
| 离散 θ 投影（Z_N） | 整数 N，由 clockwork 层数给出 | 能（格点测 cusp 位置可反解 N）| **改名\*** |
| 无质量上夸克 | 无 | — | 已被格点排除 |

\* **N 是自由参数**：论文未给出 N 的独立上下界，层数不受限 ⇒ 该路径能"符合"任何更严格的上限。
**但**它有一个格点可测的特征（θ 依赖在约化周期奇分数倍处有 cusp、全局曲率按 1/N² 标度），
**所以不判死**——判「参数自由，但有可独立定 N 的观测」。

**三条纪律**：

1. **"被数据泡软"要具体化**。若某参数取值无独立约束，则该理论对任何更严格的实验上限都自动"符合"——
   这不叫预言成功，叫**拟合成功**。
2. **"改名"不是骂人**。改名也可能是有意义的中间步骤（把问题收敛到一个可计算的量）。
   **要区分的是"它有没有给出下一步该测什么"**，而不是它有没有"解释"。
3. **能测 ≠ 已测得**。判「能独立测量」时必须**指出用哪个实验、测什么量**；
   只说"原则上可测"不给实验名字，等同于"不能测"。

## 六、第六步：双向量尺（这条最容易被跳过）

**核验者的错，必须和对方一样被公开记录。**

**实案账本（2026-11-24，两套体系五轮对抗）**：

| 谁 | 笔数 | 性质最重的一笔 |
|---|---|---|
| 我（署名者） | **10 独立 + 1 共担** | 用定义恒等式冒充验证 |
| 复核方 | 3 + 1 自查 | S³ 给 5 维盖章漏判 |

**配套三条**：

0. **自检查得出逻辑错，查不出「搬运错」（2026-11-25 新增）**——2026-11-25 那轮我 4 笔错里，
   有 2 笔**算的时候是对的**，错在后来引用自己算过的数时搬错了单位或分母
   （一处把有质量量纲的组合作「无量纲判据」引用；一处分子用质子版、分母标中子版）。
   ⇒ **凡引用自己在别处算过的数，必须重新跑一遍，不许复制。**
   ⇒ 那轮 2 笔全部由对方抓出，**我方零次自查发现**。

1. **少报也是美化**——漏记自己一笔错，和虚报对方一笔错，性质相同；
2. **"表心不一致"单独命名**——表里写的和心里想的不是同一套（s=1 与 s=1/2 口径并存、偏离因子当成公式参数、示例值未标示意）。**这类错最难自查，因为单看每一格都对。**
3. **对方主动豁免的错，仍要改**——若那处落在你署名的文本里，就是你的。

## 七、第七步：依据分级（不可省）

每个结论必须标：

| 标签 | 含义 | 可否用于下结论 |
|---|---|---|
| `【实测】` | 有外部源原文（HTTP 200 页面、PDF 某一行、正文某式） | ✅ |
| `【读码】` | 读过实际代码/资产 | ✅ |
| `【复算】` | 本机脚本跑出来的数，脚本可重跑 | ✅ |
| `【推断】` | 仅据命名、文档、二手转述 | ❌ 只能当待测假设 |

**两条铁律**：

- **外部 Agent / 任何人给的结论，若未附证据，一律降级为【推断】。**
- **【推断】不能直驱生产动作。**

**有限枚举的正确写法**：我试了六种已知组合全不是 ⇒ 这是【实测】的六次试算 + **【推断】的"找不到"**。
**"我试的都不是"不等于"它不存在"。**

## 八、一张速查表

```
拿到一套理论 →
  ├─ 拆线（A/B/C/D 分别记账，异写合并，同人不等于同书）
  ├─ 声明材料状态（正文未取到 ⇒ 只说"未提交"）
  ├─ 找它交不交数
  │    ├─ 交数 → 预注册判据 → 算 → 与已测值比
  │    └─ 不交数 → 找它的自由参数 / 必然结果 / 恒等式
  ├─ 四条杀招（范畴错误 / 恒等式冒充证明 / 缺口 / 必然当特征）
  ├─ 判「解释 or 改名」（额外输入能否被独立测量？指出实验和测量量）
  ├─ 双向量尺（自己的错同表公开，少报也是美化）
  └─ 标依据等级（【实测】【读码】【复算】可以；【推断】只能当假设）
```

## 八·补、公开前的四条伦理要求（2026-11-25 新增）

**这套方法天然有攻击性。用它的人必须先给自己划界，否则它会退化成审判工具。**

| # | 要求 | 具体做法 |
|---|---|---|
| 1 | **不评人** | 作者身份、学历、头衔、动机、商业行为——**零提及**。只谈数学结构与可检验性 |
| 2 | **材料未取到只说「未提交」，不说「错」** | 见第二步。没有正文就没有资格说它错 |
| 3 | **应用线宣称不做先验否定，也不进入评价** | 超光速 / 真空取能 / 逆龄 / 元素转变：**直到交出一条可复算的量效关系**——「在 X 条件下，输入 Y 焦耳，得到 Z 焦耳，效率 = Z/Y = ?」。给不出就停在「未评价」，既不判死也不采信 |
| 4 | **自己的错写进正文，不是脚注** | 见第六步。理由：**不这样做，整套方法就变成审判书**。写进去之后它才成立为「我用它抓自己，也用它抓别人」 |

**第 4 条本轮的实际做法**：2026-11-25 我把自己的量纲错误（杀招〇那一格我栽过）原话照录进了对外公开信，
而不是悄悄改掉。**理由是：如果我只说别人错、不说自己错，那封信就只是审判书。**

**另一条经验**：把「范畴错误」写软的版本＝把「所有尺度通用」改成「同一类结构的统一命名，具体判据逐尺度给出」。
**改话术本身不算成果，它只是把「无法检验」变成「可以检验」。真正成果从交出第一个数开始。**
（这一条必须写在旁边，否则会被读成「说软话就能过关」。）

---

## 九、这套方法自己失败的时候

**必须诚实记录**：

1. **它对"拒绝回应"无解。** 2026-11-11 我向三个正在讨论同一问题的 GitHub 仓库投了可复算的数，
   **三个全部没有回复**。方法正确 ≠ 对话会发生。
2. **它需要对方愿意被算。** 对"你算的是错的，但我不看你算的"这类回应，本方法没有强制力。
3. **它会消耗大量互相找错的时间**。五轮对抗换来 13 笔认错——**效率不高，但记录是干净的**。
4. **它的最大风险是"用尺子赢人"**。所以第〇条那句"阴性结果同样有价值"不是修辞，
   是**防止这套方法退化成攻击工具的唯一约束**。
