## 为什么放在这里

本仓库战线 ① 核的是**已确立物理**里的数（θ̄、真空能）——那些有标准答案可以对。

战线 ② 是回不去的部分：**有人递来一套自称能解释一切的体系，该怎么接？**

2026-11-25 对一份定性框架型文档做了三轮对抗核验（对方是一位同样在做独立复算的 AI 助手，不是原作者）。**结论不重要，方法留在这里。**

> **三条落地的收获**，都已回写进 `docs/method.md`：
> 1. **范畴错误比数据缺口更重**——数据缺口会随时间补上，范畴错误不会。判它不需要数值输入，看量纲即可。
> 2. **判据必须不能被措辞消解**——若你的批评能被一句「那不就是某某吗」化解，说明判据选错了。
> 3. **无限定强断言是核验者自己最容易犯的错**——本文「我自己的错」一节有 3 笔实例。

## 核验结论摘要（三格并排）

本轮把三份材料放在同一把尺子下。**名字一律隐去**——因为本文档要说的是「一类操作错误」，不是「谁错了」。

| | A 体系 | B 体系 | C 体系 |
|---|---|---|---|
| 数学密度 | **最高**：100 页母方程、23 页引力推导、泊松方程求解、兰姆位移与反常磁矩独立复算 | **中**：有临界转速判据、自旋角动量式，可纯代数联立 | **零**：无方程、无变量定义、无数值 |
| 最硬内伤 | `G = 4πc²/μ_g` 是**循环定义**——`verify_prior_carryover.py` 四行归零 | 所谓「普适背景参数」对电子与质子差 **1836 倍**，与其自身「单一密排不可压缩」前提自相矛盾 | 「Ω 拐点六尺度通用」在量纲上不成立（`verify_case_c_eight_checks.py` 第 E1 项） |
| 是否可当场验 | ✅ 一个计算器，30 秒 | ✅ 一次除法 | ✅ 一张量纲表 |
| 判定 | 重述 | 自相矛盾 | 范畴错误 |

**⇒ 三份材料失败的位置完全不同，失败的方式是同一个：把「重述」当「预言」，把「命名」当「普适」。**

**而数学密度最高的那一格（A），栽得和「零方程」那一格（C）一样干净。**

**这条是本轮唯一的结论，也是它可以被推广到下一个体系的原因。**

## 三个可当场执行的自检（从本轮对抗里提炼）

### 自检一：常数代入看是否恒等

> 把公式里所有常数用实验值代入，看结果是不是恒等于自己。
>
> - **恒等 ⇒ 那是重述，不是推导**
> - 不恒等，且差一个可测量的量 ⇒ 那才可能是预言，去核这个差

A 体系翻车点：`μ_g = 4π(c²/G)`，`c²/G` 是普朗克单位标准量。**于是「两个基本常数」只是给标准量换了个名字，还多带一个 4π。**

### 自检二：单一参数能否跨对象复用

> 若某体系称某参数为「普适」「背景」「不变」，就把它代入两个已知量差很大的对象，看算出什么。

B 体系翻车点：该参数对电子与质子差 1836 倍。**「普适」与「差 1836 倍」不能同时成立。**

### 自检三：量纲表

> 把「某规则在所有尺度通用」这句话拆成每个尺度一行，逐行问：**这一格的临界判据是什么量纲？有没有真 O(1) 无量纲判据？**

C 体系翻车点：六尺度里只有恒星坍缩有真判据（钱德拉塞卡极限）；其余五个不是「还没算」，是**不能这么算**。

**关键一行**：衰老的死亡率 `μ(a) = A·e^{Ba}` **处处解析、无奇点**；相变的序参量 `Ψ ~ |t|^β` 在临界点**非解析、导数发散**。
**这是两种不同的数学对象，不是同一个对象的两个例子。**

```bash
python3 verify_case_c_eight_checks.py    # 第 ⑥ 项：Gompertz 斜率收敛 vs Ising 斜率发散
```

## 我自己的错（正文，不是脚注）

按 `docs/method.md` 第六条「双向量尺」：**核验者的错必须和对方一样被公开记录。少报也是美化。**

**本轮我 4 笔，对方抓出 2 笔，我自查抓出 2 笔。**

| # | 我写的 | 真值 | 谁抓的 | 性质 |
|---|---|---|---|---|
| 1 | 「真正的判据是**无量纲**组合 `(ℏc/G)^{3/2}/m_N²` 达 O(1)」 | 该组合量纲 = **M（质量）**，数值 ≈ 1.8477 M☉。真无量纲判据是 `M / 该尺度` | **对方** | **举着量纲检查的旗砸自己** |
| 2 | `M_Ch/[(ℏc/G)^{3/2}/m_N²] = 0.7794` | `2.8640/3.685 = 0.7772`（质子版）。0.7794 对应中子版——**分母标中子、分子用质子，不同源** | **对方** | **表心不一致**（写的不是自己算的） |
| 3 | 批评对方「没给逆映射（给 0 个）」 | 该批评可被「逆映射就是时间反演」一句话化解 ⇒ 属**无限定强断言**，违反本仓库 protocol 的三条硬规则 | **我** | 判据可被措辞消解 |
| 4 | 用「CMB 2.725 K 存在」反驳「其它假说缺归藏段」 | CMB 是大爆炸复合期（约 38 万年后）的**生发段化石**，不是**归藏段**（衰亡/热寂）证据。打偏靶子 | **我** | 论据与结论不同类 |

### 从这 4 笔里析出的两条规则

**① 自检能查出逻辑错，查不出「搬运错」。**
第 1、2 笔都不是算错——算的时候是对的。错在**后来引用自己算过的数时搬错了单位/分母**。
⇒ **规则：凡引用自己在别处算过的数，必须重新跑一遍，不许复制。**
⇒ 本轮两笔由此产生，我方零次自查发现，**100% 由对方抓出**。

**② 判据须先自问：「这句批评能不能被一句话化解？」**
第 3 笔的原始判据（须给逆映射）在措辞上无懈可击，在逻辑上一个词就化解了。
⇒ 换成**熵账判据**：「若全域闭环、逆映射把一切抹平，那么恒星坍缩/衰老/灭绝产生的熵去哪了？要么给熵汇（说明不闭合），要么承认不闭合。」
⇒ **热力学第二定律不是措辞问题，所以这条挡得住。**

```bash
python3 verify_v2_dimension_check.py   # 第 1 笔的可复现自查（含量纲代数 assert）
```

## 我在本轮守住的边界

**核验者最容易越的界，是顺手评价人。本轮一条未越：**

| 不评的 | 做法 |
|---|---|
| 作者身份、学历、头衔、动机、商业行为 | **全文零提及** |
| 「这套体系有没有价值」 | 不判死。只判「它现在能不能被检验」 |
| 应用线宣称（超光速 / 真空取能 / 逆龄 / 元素转变） | **不做先验否定，也不进入评价**——直到交出一条可复算的量效关系：`「在 X 条件下，输入 Y 焦耳，得到 Z 焦耳，转换效率 = Z/Y = ?」` |
| 材料未取到的部分 | **只说「未提交」，不说「错」**（`docs/method.md` 第二步） |

**这条边界对对方是保护，不是攻击**：一旦把「个人诠释」当「原著内容」，原著就永远进不了学术讨论。

## ⚠️ 一条不能含糊的边界：脚本复现的是「我的推导」，不是「原文档」

三份脚本全部**只用标准库、只含本仓库作者自己写的算式与常数**，不引用对方任何数据文件。
所以：

| 你能复现的 | 你不能从本仓库复现的 |
|---|---|
| 「`(ℏc/G)^{3/2}/m_N²` 量纲是 M」 ✅ | 「原文档第几页确实这么写」 ❌（原件未转载） |
| 「4πc²/μ_g 代回是恒等式」 ✅ | 「原作者是否另有后续定义」 ❌ |
| 「Gompertz 与 Ising 临界行为不同」 ✅ | 「原作者如何回应这条」 ❌ |

**⇒ 本目录的证据链是「操作 → 结果」，不是「原文 → 结论」。** 这个区别必须留在明面上，
否则读者会以为这里能替代读原文。**不能。**

## 本目录结论的依据等级

| 等级 | 用在哪 |
|---|---|
| 【实测】 | **无。** 本目录没有任何【实测】级物理结论——被审对象里没有一个可运行之物 |
| 【读码】 | 读过三轮对方原件全文（sha256 已校验） |
| 【复算】 | 循环定义四行归零、1836 倍、量纲检查、Gompertz vs Ising 形状、普适类指数三值 |

**「零【实测】」≠「零结论」**：零【实测】指被审对象里没有可运行之物；本目录的【复算】级结论是可核查的确定判断。
**它们不确定的是「被审体系对不对」，不是本文自己说的对不对。**
