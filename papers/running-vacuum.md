## 三、核心计算：nu = 0.109 到底意味着什么

### 3.1 我的自洽方程【复算】

```
RV: ρ_vac(H) = (3/8πG)[c₀ + ν H²]      （Solà 标准形式）
自洽 Friedmann：E²(a)(1−ν) = Ω_m a⁻³ + Ω_Λ − ν
⇒ E²(a) = [Ω_m a⁻³ + Ω_Λ − ν]/(1−ν)
检查 a=1: E² = [Ω_m + Ω_Λ − ν]/(1−ν) = [1−ν]/(1−ν) = 1 ✅
```

### 3.2 用 Model B 实测值 Ω_m=0.2978, ν=0.109 代入

| 1.5 | — | 1.123 | +12.3% |
| 10 | 445.5 | **70.0** | +6900% |
| 1100 | 4.461×10⁸ | **6.92×10⁷** | 早期巨大 |

**⇒ rho_vac 在 z=10 时是今天的 70 倍。** 这不是「缓变」，这是「剧变」。

### 3.3 关键对照：这与 Solà 组的描述矛盾

**Solà 2026 综述说**：「ρ_vac evolves **very slowly** with the expansion, δρ_vac ~ O(m_Pl² H²)」
**2808.23633 拟合出**：ν=0.109，即今天 15.5% 的 ρ_vac 来自 νH² 项，z=10 时涨到 70 倍

**我方判定：倾向 (b)，但我无法从摘要确认，需读两文正文的定义式对比。标【推断】。**

## 四、QFT 自然性检验（这是本轮最硬的一击）

### 4.1 我的复算

```
ν_QFT = (1/6π) Σ B_i (M_i/M_P)²
最重已知基本粒子：顶夸克 m_t = 173 GeV
m_t/M_P = 173×10⁹ / 1.221×10²⁸ = 1.417×10⁻¹⁷
(m_t/M_P)² = 2.008×10⁻³⁴
ν_QFT ≈ (1/6π)×2.008×10⁻³⁴ = 1.07×10⁻³⁵
```

**若 ΣB_i ≈ 1（量级估计）**：

> **ν_QFT ~ 10⁻³⁵**

### 4.2 与拟合值的差距

| 量 | 值 |
|---|---|
| ν_QFT（含顶夸克） | **1.07×10⁻³⁵** |
| ν_QFT（论文自述「≪1」允许的上限，取 10⁻³） | 10⁻³ |
| **论文拟合值** | **0.109** |
| **差距（vs 严格 QFT）** | **10³⁴ 倍** |
| 差距（vs 论文自己说的「≪1」） | 10² 倍 |

### 4.3 反解：需要多重的粒子才能给 ν=0.109？

```
ν = (1/6π)(M/M_P)²  ⇒  M/M_P = √(6πν)
ν=0.109: M/M_P = √(6π×0.109) = √2.055 = 1.434
⇒ M ≈ 1.43 M_P ≈ 1.75×10²⁸ eV ≈ 1.75×10¹⁹ GeV
```

**⇒ 要 ν=0.109，需要存在质量约 1.4 倍 Planck 质量的粒子。**

**这不可能是「已知粒子」**——已知最重的是顶夸克（173 GeV），差 10¹⁷ 倍。

### 4.4 三种可能的出路（我列出来，但不替论文辩护）

| 出路 | 代价 |
|---|---|
| ① ν 只是唯象拟合参数，与 QFT 无关 | 那就不能宣称「RVM 有 QFT 起源」 |
| ② 存在 Planck 质量新物理 | 与所有已知物理矛盾 |
| ③ 论文的 ν 定义与我用的不同 | 需读正文确认，标【推断】 |

**⇒ 这一条是本轮最有价值的问题，我已提给各智能体和 WB。**

    print("nu=%.3f  w_eff=%.6f" % (nu_v, -1-d/3))

## 附：BBN 错误的完整复盘（11-10 23:05 补）

**我原本写**：ρ_vac/ρ_rad = 8.4×10⁻¹⁰，结论「RV 不死于 BBN」。

**真值**：0.362。

**错在哪**：8.4×10⁻¹⁰ 这个数我无法回溯出任何算法。

```
ρ_vac(z) = ρ_crit0·[Ω_Λ + ν(E²(z) − 1)]
z=1100: E² = 4.4608e8
        ρ_vac = 0.7022 + 0.109×(4.4608e8 − 1) = 4.862e7  [单位 ρ_crit0]
        ρ_rad = 9.15e-5 × 1101^4 = 1.345e8
        ratio = 4.862e7 / 1.345e8 = 0.3616
```

**这个错为什么重要**：它把一个「已死的模型」写成了「未被排除」。
