## 四、系数三连这一课

这是九轮里**最硬的方法教训**，也几乎是唯一能直接教给别人的东西：

> **数字与符号须由同一表达式打印。** 凡是手打在正文里的数，事后都成了要认罚的坑。

三次发作、各自对应的数（全部可由 `scripts/letter-recompute-appendix.py` 重算，【复算】）：

- **R81**：脚本写了正确的表达式 `λ_thr = π·λ̄_C`，标签却手打「2π」。A 组复算表明：`h = 2πℏ` ⇒ `λ_thr = hc/(2m_ec²) = π·ℏ/(m_ec) = π·λ̄_C`，系数是 **π**；若改用普通康普顿波长则 `λ_thr = ½·λ_C`。**两种定义都得不到 2π。**
- **R83①**：λ_thr（1213.1551 fm）与 λ̄_C（386.1593 fm）互换——E 组与 A 组把三个波长同时打印，差值一目了然。
- **R83②**：正文写 `m = ℏf/c²` 却给出 `0.11787 meV`——那是 `h f/c²` 的数。E 组复算：按 ℏ 得 `0.018759 meV`，按 h 得 `0.117867 meV`，比值 `= 6.2831853 = 2π`。**标签与数值差 2π，正是 C5 的病源。**

## 五、从判死到给靶

早期习惯是「判死」：指出某条路物理上过不去。但判死不交数，对方无从反驳，自己也懒得算。后来改成**给靶**：

- **C4 实例**：我方 R82 曾「换门打靶」——立了 λ_thr 门（1.2132 pm），靶却用 λ̄_C 门去算 `7.763e20 Hz / 3.211 MeV`。改正后，λ_thr 门靶 = `2.471180e+20 Hz` / `1.021998 MeV`，恰好等于 2m_ec²（正负电子对产生的 Breit-Wheeler 阈值），物理自洽。
- **D 组条件式推理**（【复算】）：若 28.5 GHz 是特征频率，则 `ℓ = c/f = 10.52 mm`；`ℓ/λ̄_C = 2.7e10 = 10^10.4`（远大于 1），`ℓ/λ_thr = 8.7e9`。按丙路线判据（局域化长度须 ≤ 康普顿尺度），台阶②当场判死。**注意**：我们不采信「28.5 GHz 是水分子共振/本原心跳」的宣称（C8 冻结案未翻），只说「若按你自己的数代入你自己的门，会得到什么」。

**给靶比判死有用**——靶是共同的、可复算的，谁都能照着算一遍，错了当场现形。

## 九、给独立研究者的五条可操作建议

1. **先把叙事拆成台阶**：任何「本原/涌现/统一」的宏大叙事，先切成一级级可独立验证的台阶。
2. **每级交出数**：每一级都必须交出一个与已测量可比的具体数值，不是形容词。
3. **用别人的门之前先确认是哪一扇**：判死或给靶，先写明用的是哪一道门槛。
4. **数字与符号同源打印**：正文里的数和公式符号，都由同一段脚本同一表达式打印，禁止手打。
5. **接受分治、别硬撑「统一」**：承认某些尺度需要独立的、已测的机制，不强行用一套方程贯通全部质量。

## 十、边界与止损线

- **C8**：R71–R85 冻结判据**一条未翻**；本轮**零【实测】**。
- **JHEP 引用边界**：只引用 JHEP 10(2023)172 给出「层级涌现的机制」，**绝不声称它给出 m_μ/m_e 的精确值**。
- **丙′ 标【推断】**：QCD 质量生成为第三条路，属【推断】级，非【实测】级。
- **不做先验否定，但无法评价就不评价**：对算不出精确值的部分，只说「这一关过不了」，不延伸至「整条路全错」；对无法复算的部分，诚实标注「无法评价」。
- **不碰人、不碰产品、不碰动机**：本原体系只作案例；不评价其商业体系、不揣测动机；不联系作者、不代发。

九轮走到这里，共识归零在一件朴素的事上：我们都同意「精确比值这一关，以普朗克尺度起步的体系过不了」，也都同意「层级机制有真实论文背书、是活的」。剩下的不是分歧，是措辞。把措辞写清楚，把尺子摆平，就是这封信全部想做的事。

## 登记：本轮方法学增量（对 `docs/method.md` 的补充素材）

1. **共识可以冻结**：C1–C8 证明「双方签认的判据集」是可执行的制度——冻结后一条未翻，翻案须交新证据。这比「每轮重新吵判据」效率高一个量级。
2. **呈现层错误 ≠ 对账错误**：C4/C5 两次「手打标签错」（ℏ-h、门-数）被明确归入**不计对账**。这条区分保护了「认错」的诚实性——否则认错会被通胀成计票筹码。
3. **单位错三例（两在我方）**：11-24 我方 eV 重复除 e（`2×10²⁵ MeV`）、11-27 我方脚本 me(J) 误当 kg、MeV→eV 误除 1e6。三次同根：**量纲没有跟着变量走**。已固化为脚本内自建常量 + 断言。
4. **结构呼应的计数律检验**：`2^k`（易之层级）vs `k`（本原自然数链）——**同构声称必须先过计数律**，否则只是修辞。这是「概念像 vs 数学是」（method.md 第三节）的强化版。
5. **公开信三标题与五项自核**：纪要/台阶/系数三连三个方向，禁用「证伪/终结/认输/判决」；自核五项（条款一字不改、JHEP 只写机制不给 206.768、丙′ 代价写全、不写我方赢了、不碰人产品动机）。这五项是「不判死」尺子在**语言层面**的落地。
