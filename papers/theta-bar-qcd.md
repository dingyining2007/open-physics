## 〇、先说结论（三条，按重要性排）

### 结论 1：**「θ̄ < 1.18×10⁻¹⁰」这个数是 2006 年的实验 + 1999 年的理论，已经过时**

【复算】

```
ILL 2006 上限 2.9×10⁻²⁶ e·cm  ÷  Pospelov-Ritz 1999 PRL 系数 2.4×10⁻¹⁶ e·cm
= 1.208×10⁻¹⁰
```

**这就是 1.18×10⁻¹⁰ 的来源。**（1.18 与 1.208 差 2.3%，可能来自不同版本的系数取值，我无法确认是哪一版）

**但两个输入都已更新：**
- **实验**：PSI nEDM 2020（PRL 124, 081803）给出 `d_n = (0.0 ± 1.1_stat ± 0.2_sys)×10⁻²⁶ e·cm`，合并 σ = 1.118×10⁻²⁶
- **理论**：arXiv:2608.22587（Blum et al. 2026-08-23，格点 QCD）给出 `d_n = −0.0050(4)(8)·θ̄ e·fm`

**用这两项重算：**

```
|d_n/θ̄| = 0.0050 e·fm = 5.000×10⁻¹⁶ e·cm
PSI 2020 的 90% CL 上限 = 1.645 × 1.118×10⁻²⁶ = 1.839×10⁻²⁶ e·cm
⇒ |θ̄| < 1.839×10⁻²⁶ / 5.000×10⁻¹⁶ = 3.68×10⁻¹¹
```

### **⇒ 当前应有 |θ̄| < 3.7×10⁻¹¹，比 1.18×10⁻¹⁰ 紧 3.2 倍。**

---

### 结论 2：**理论系数本身散布 3 倍，这是链条上最大的不确定来源，不是实验**

【实测】四个独立方法给出的 d_n(θ̄) 系数：

| 方法 | 来源 | d_n/θ̄ (e·cm) | 相对倍率 |
|---|---|---|---|
| 手征估计 | Crewther–Di Vecchia–Veneziano–Witten 1979, Phys.Lett.B 88, 123 | 3.6×10⁻¹⁶ | 0.72 |
| QCD sum rule | Pospelov–Ritz 1999, PRL 83, 2526 | 2.4×10⁻¹⁶ | 0.48 |
| QCD sum rule NNLO | Pospelov–Ritz 2000, Nucl.Phys.B 573, 177 | 1.2×10⁻¹⁶ | **0.24** |
| 格点 QCD | Blum et al. 2026, arXiv:2608.22587 | **5.0×10⁻¹⁶** | 1.00 |

**最大与最小差 4.2 倍。**

**注意**：Pospelov-Ritz 自己两篇论文（PRL 1999 与 NPB 2000）就差了 2 倍，且 NPB（更详细的 NNLO 计算）给出的值更小。**同一作者、同一方法、更精细的计算把系数砍了一半**，这是个警示信号。

**⇒ 因此 |θ̄| 的上限值本身就带 ≥4 倍的系综不确定度。任何声称「θ̄ < 1.18×10⁻¹⁰ 精确到两位有效数字」的表述都是假的精度。**

---

### 结论 3：**格点论文自述的 |θ̄| ≲ 10⁻¹¹ 与它自己的数据和实验上限对不上**

【复算】

Blum et al. 2026 摘要原文：

> "Comparison with the current experimental bound on nEDM implies constraint **|θ̄| ≲ 10⁻¹¹**"

**用 PSI 2020 上限复算：**

| 置信水平 | d_n 上限 | ⇒ \|θ̄\| 上限 |
|---|---|---|
| 1σ | 1.118×10⁻²⁶ | **2.24×10⁻¹¹** |
| 90% CL | 1.839×10⁻²⁶ | **3.68×10⁻¹¹** |
| 95% CL | 2.191×10⁻²⁶ | **4.38×10⁻¹¹** |

**要得到 |θ̄| ≤ 10⁻¹¹，需要 |d_n| ≤ 5.0×10⁻²⁷ e·cm，比 PSI 2020 的 90% CL 上限紧 3.7 倍。**

**⇒ 论文的 10⁻¹¹ 无法从 PSI 2020 数据复现。** 三种可能：
- (a) 他们用了更紧的（我未查到的）新实验上限
- (b) 他们用 θ̄ 的贝叶斯后验而非频率派上限
- (c) 这是个"≲"的宽松写法，实际指"量级"

**我标为「未确认」，不做判定。** 但这说明：**摘要里的结论数字必须复算，不能直接引用。**

## 一、完整链条拆解（五步）

```
实验测量 d_n
    ↓ [实验误差 σ_stat, σ_sys]
d_n 的上限 |d_n| < Z·σ
    ↓ [理论系数 C = d_n/θ̄ —— 四种方法差 4.2 倍]
|θ̄| < |d_n|max / |C|
    ↓
θ̄ 的精细调谐量级 = 1/|θ̄|
    ↓ [与 CKM 相位 δ_CKM ≈ 1.14 rad 对比]
strong CP problem
```

**每一步的数字：**

### 第 1 步：实验

| 实验 | 结果 | 年份 |
|---|---|---|
| ILL nEDM | \|d_n\| < 2.9×10⁻²⁶ e·cm (90% CL) | 2006 |
| **PSI nEDM** | **d_n = (0.0±1.1_stat±0.2_sys)×10⁻²⁶ e·cm** | **2020** |

【实测】两个数值均取自期刊摘要原文（PRL 97, 131801；PRL 124, 081803）

**PSI 2020 合并不确定度：**

```python
σ_comb = sqrt(1.1² + 0.2²) × 10⁻²⁶ = 1.118×10⁻²⁶ e·cm
```

### 第 2 步：转成上限

```python
Z = 1.645  (90% CL，单边高斯)
|d_n| < 1.645 × 1.118×10⁻²⁶ = 1.839×10⁻²⁶ e·cm
```

**⚠️ 口径声明**：这里用「高斯近似 + 单边单侧」给上限。如果实验组用的是「与零无显著差异 ⇒ 给上限」的贝叶斯方法（UCL），结果可能不同。**我没查 PSI 2020 原文用的是哪种，标【推断】。**

### 第 3 步：理论系数

见上文结论 2 表。

**格点值的单位换算（易错，必须显式写）：**

```
d_n = −0.0050 θ̄ e·fm
1 fm = 10⁻¹³ cm
⇒ d_n = −0.0050 × 10⁻¹³ θ̄ e·cm = −5.0×10⁻¹⁶ θ̄ e·cm
```

### 第 4 步：得 |θ̄| 上限

| 系数来源 | \|θ̄\| < (90% CL) |
|---|---|
| 格点 2026（5.0×10⁻¹⁶） | **3.68×10⁻¹¹** |

**跨度：3.7×10⁻¹¹ ～ 1.5×10⁻¹⁰，** 5 倍。**

## 二、θ̄ 为什么比 Higgs 等级问题更"难受"

**这是本轮我最想强调的一点，也是我原来没想清楚的。**

### 两者的结构完全不同

| | Higgs 质量 | θ̄ |
|---|---|---|
| 修正类型 | **加性发散** δm_H² ~ Λ²/(16π²) | **加性有限** |
| 为什么难 | 需要抵消 (Λ/m_H)² | 需要有限贡献精确相消 |
| 有无对称性保护 | 手征对称性（费米子）不保护标量 | **只有 PQ 对称性** |
| 数值调谐 | (v/M_Pl)² = 4.1×10⁻³⁴ | 2.7×10⁻¹¹ |

**⚠️ 注意：Higgs 的 4.1×10⁻³⁴ 比 θ̄ 的 2.7×10⁻¹¹ 小 23 个数量级。就"数字小"而言 θ̄ 远不如 Higgs 严重。**

### 但 θ̄ 的难点在别处

**θ̄ 的问题不是"数太小"，是"没有理由小"：**

1. **CKM 相位是 O(1) 的**：δ_CKM ≈ 1.14 rad ≈ 65.4°
2. **如果 CP 破坏只有一个来源（CKM），那 θ̄ 应该由同一机制产生，量级 O(1)**
3. **实际 θ̄/δ_CKM < 10⁻¹¹** ⇒ 两个 CP 相位相差 11 个数量级
4. **θ̄ 还受任意高能标的新物理贡献**：任何在 M 处的新物理，若 CP 破坏是"一般"的，单圈贡献 δθ̄ ~ (α/4π)·Im(相位) ~ 10⁻³

**⇒ 要让 θ̄ 保持 10⁻¹¹，必须要么 PQ 对称性，要么质量矩阵强制实（Nelson-Barr），要么 CP 在高能完全守恒。**

**这个"为什么 CP 相位有两个差 11 个数量级的值"才是问题的真核。** 而不是"数很小所以不自然"。

## 三、当前的解有哪些（截止 2026-11，我查到的）

【实测】以下均为 arXiv 摘要原文核过：

| 方案 | 代表文献 | 机制 | 状态 |
|---|---|---|---|
| **PQ 轴子** | Weinberg 1978; Wilczek 1978 | 动学松弛 θ̄ → 0 | 主流，但有 axion quality 问题 |
| **Nelson-Barr** | Nelson 1984; Barr 1984 | 质量矩阵强制实 | 需精细构造 |
| **左右对称 P/CP** | Maiezza et al. 2014 (1407.3678) | P 使 θ̄=0，破缺后辐射产生小值 | 需检验 |
| **规范离散对称 P/CP** | Benabou et al. 2025 (2510.18951) | 引力产生的 gauge discrete P/CP 强制真空 CP 守恒 | **2025-10 新论** |
| **离散 θ 投影** | Mir et al. 2026 (2603.05195) | 规范 Z_N ⊂ 2π 平移，orbifold 选最近 CP 点，\|θ̄\|≤π/N | **2026-03 新论** |
| 无质量上夸克 | 已被格点排除 | — | ❌ 已死 |

### 特别提两条 2025-2026 的新方案

**① Benabou et al. 2025（arXiv:2510.18951）「Clearing up the Strong CP problem」**
摘要要点：
- 反驳"离散对称解失效"的近期说法：若 P 或 CP 作为**规范离散对称**（量子引力可能产生）实现，真空必然保持 CP
- 论证"strong CP 问题是幻觉"的说法不成立：θ̄≠0 时 nEDM 非零，直接来自 QCD 动力学
- 结论：强化 strong CP 问题的真实性

**② Mir et al. 2026（arXiv:2603.05195）「Discrete θ Projection」**
摘要要点：
- 不用轴子，**规范化 θ 的 2π 平移对称的一个 Z_N 子群**
- QCD 耦合到紧致、局域、gapped 拓扑扇区 ⇒ 路径积分 orbifold
- 大四维体积极限下真空能为 orbifold 像的**下包络**，动力学选择最接近 CP 对称点的分支
- **强制 |θ̄| ≤ π/N，不假设先验小值**

**⇒ 这条如果成立，它给的是硬界限 |θ̄| ≤ π/N。要满足 3.7×10⁻¹¹，需 N > 8.5×10¹⁰。这是个可被检验的预言——N 不能太小。**

## 五、我这一轮自己核出来的三个坑

### 坑 1：单位换算 e·fm → e·cm 容易丢 10⁻¹³

```
d_n = −0.0050 θ̄ e·fm
1 fm = 10⁻¹³ cm
⇒ −5.0×10⁻¹⁶ θ̄ e·cm  ← 必须乘 10⁻¹³
```

漏乘就得出 |θ̄| < 3.7×10⁻²⁴ 这种荒谬结果。

### 坑 2：1σ / 90% CL / 95% CL 混用

同一篇文章里 `|d_n| < 2.9×10⁻²⁶ (90% CL)` 和 `d_n = 0.0±1.1` 是**不同的量**。
- `±1.1` 是 1σ
- `2.9e-26` 是 90% CL 上限（≈1.645σ）

**混用会让 |θ̄| 上限差 1.645 倍。**

### 坑 3：χ(0)^(1/4) vs χ(0)^(1/2)

轴子质量公式是 `m_a f_a = √χ(0)`，不是 `= χ(0)`。
`χ(0)^(1/4) = 75.5 MeV` ⇒ `χ(0)^(1/2) = (75.5 MeV)² = 5.70×10¹⁵ eV²`

**我第一次写成了 χ(0) 直接取 75.5 MeV 的平方根，得出 m_a 大了 10³ 倍。**

## 七、对丁宁原问题的答复

**问：θ̄ < 1.18×10⁻¹⁰ 这条链对不对？**
**答：链条对，数字旧了。**

| 环节 | 状态 |
|---|---|
| 1. nEDM 实验给 d_n 上限 | ✅ 正确 |
| 2. d_n = C·θ̄ 线性关系 | ✅ 正确（QCD 真空能 ∝ θ̄²，观测量 ∝ θ̄） |
| 3. C 的数值 | ⚠️ **四种方法差 4.2 倍** |
| 4. C = 2.4×10⁻¹⁶ + 上限 2.9×10⁻²⁶ | ⚠️ **都是 1999-2006 的旧值** |
| 5. 结论 1.18×10⁻¹⁰ | ❌ **应更新为 3.7×10⁻¹¹** |

**⇒ 更新后：|θ̄| < 3.7×10⁻¹¹，调谐 2.7×10¹⁰ 分之一。**

**问：这条链值不值得主攻？**
**答：值得，但重点不在"再压一个量级"。**

理由：
1. **实验端**：n2EDM / nEDM@SNS / TUCAN 会把 σ 压到 10⁻²⁷ → |θ̄| 到 10⁻¹²
2. **理论端**：格点正在把系数 C 的 4 倍不确定度压到 10%（Blum et al. 2026 已做到 18%）
3. **真正的判据**：**如果 C 被钉死在 5.0×10⁻¹⁶ ± 18%，那么 nEDM 每提高一个量级，θ̄ 上限就硬压一个量级，无任何理论逃生口**
4. **⇒ 这是少数几个"实验进步 = 物理结论进步"的干净通道**

**⇒ 建议：把 θ̄ 作为主攻方向成立。但攻的不是"θ̄ 有多小"，而是"为什么两个 CP 相位差 11 个数量级"。**

## 八、可复现脚本

```python
import math

# ===== 实验输入 =====
dn_stat, dn_syst = 1.1e-26, 0.2e-26          # PSI 2020
dn_ill = 2.9e-26                              # ILL 2006, 90% CL
sigma = math.hypot(dn_stat, dn_syst)          # 1.118e-26

print("sigma_comb = %.4e e.cm" % sigma)
for z, lab in [(1.0,"1sig"), (1.645,"90%CL"), (1.96,"95%CL")]:
    print("  %-6s |d_n| < %.3e" % (lab, z*sigma))

# ===== 理论系数 =====
C = {
  "CDVW 1979":        3.6e-16,
  "PR 1999 PRL":      2.4e-16,
  "PR 2000 NPB":      1.2e-16,
  "Lattice 2026":     abs(-0.0050)*1e-13,     # e.fm -> e.cm
}
print("\n coefficients and theta-bar bounds (90% CL):")
for k, v in C.items():
    print("  %-14s C=%.2e   |theta|<%.3e" % (k, v, 1.645*sigma/v))

# ===== 旧值溯源 =====
print("\n old value trace:")
print("  %.3e / %.1e = %.3e" % (dn_ill, 2.4e-16, dn_ill/2.4e-16))

# ===== 轴子质量 =====
chi_half = (75.5e6)**2       # eV^2
print("\n axion mass:")
for fa in [1e9, 1e10, 1e11, 1e12]:
    print("  f_a=%.0e GeV -> m_a=%.3e eV (%.2f ueV)" % (fa, chi_half/(fa*1e9), chi_half/(fa*1e9)*1e6))
```
