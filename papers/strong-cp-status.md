## 一、问题是什么（三行）

```
θ̄ ≡ θ_QCD + Arg Det M_q
```

只有这个组合在手征重定义下不变，因而是物理的强 CP 相位
【实测 · Ai et al. 2026, arXiv:2609.00620 式(1.2)–(1.5)】。

- 无保护机制时，自然预期 `θ̄ ~ O(1)`
- 实验给出 `|θ̄| < 10⁻¹⁰` 量级
- **`θ̄` 为什么这么小** = strong CP 问题

**这个问题的尖锐性来自 CKM 的存在**：弱作用里 CP 破坏是确实存在的（δ_CKM ≈ 65.4°，O(1)），
所以不能说"宇宙就是 CP 守恒的"。同一个标准模型里，一个 CP 相位是 O(1)，另一个被压到 10⁻¹⁰。

## 二、输入数据（每个数都标出来源和口径）

### 2.1 实验：中子电偶极矩

| 实验 | 结果 | 出处 | 依据 |
|---|---|---|---|
| ILL 2006 | `|d_n| < 2.9×10⁻²⁶ e·cm` (90% CL) | hep-ex/0602020, PRL 97, 131801 | 【实测】原文逐字核对 |
| **PSI 2020** | `d_n = (0.0 ± 1.1_stat ± 0.2_sys)×10⁻²⁶ e·cm`<br>原文直接给 `|d_n| < 1.8×10⁻²⁶ e·cm` (90% C.L.) | arXiv:2001.11966, PRL 124, 081803 | 【实测】原文逐字核对 |

> **⚠️ 一个必须并存两个数的地方**
>
> PSI 原文**直接给了 1.8×10⁻²⁶**，没有走 1.645σ 那条路。反推：
> `z = 1.8 / √(1.1²+0.2²) = 1.8/1.1180 = 1.61`，**不是 1.645**。
>
> - 用原文 1.8 ⇒ `|θ̄| < 3.60×10⁻¹¹`
> - 用 σ_comb 自推 1.645σ = 1.839 ⇒ `|θ̄| < 3.68×10⁻¹¹`
>
> 差 2.2%。**来源是"原文已给数，又自己推了一遍"**——多算一步反而偏离原文口径。
> 本仓库两个数都写，不选一个来掩盖另一个。（见 issue #2）

### 2.2 理论：`d_n` 与 `θ̄` 的比例系数

这一步的不确定度**大于实验**，且各家差 4 倍：

| 方法 | `d_n/θ̄` (e·cm) | 备注 |
|---|---|---|
| 手征估计 (Crewther et al. 1979) | 3.6×10⁻¹⁶ | 老估计 |
| QCD sum rule (Pospelov–Ritz 1999, PRL) | 2.4×10⁻¹⁶ | **流传最广** |
| QCD sum rule (2000, NNLO) | 1.2×10⁻¹⁶ | 修正后大幅下降 |
| 格点 QCD (2026, arXiv:2608.22587) | **5.0×10⁻¹⁶** | 首个统计显著信号 |

**最大与最小差 4.2 倍。** ⇒ 任何声称 θ̄ 上限"精确到两位有效数字"的表述都是假精度。

### 2.3 格点 2026 的结果细节（核到原文）

arXiv:2608.22587 正文式(1)、式(18)原文【实测】：

> `θ̄ = θ_QCD + Arg Det M_q` **is the physical theta-angle** (including the phase of the quark mass matrix M_q)
> `d_n/θ̄ = −0.0050(4)(4)` for `|n_z|=1`；`d_n/θ̄ = −0.0043(3)(3)` for `|n_z|=2`
> 取 `|n_z|=1` 为中心值（高阶修正更小），总系统误差 = 拟合区间不确定度 ⊕ 两值之差，
> 得 `d_n/θ̄ = −0.0050(4)(8)`

**两条要点**：

1. **算的是 `θ̄` 不是 `θ`** ⇒ 可与 sum rule 直接比较，原来"×2 量级"的疑虑解除（见 issue #1）
2. **16% 差异（0.0050 vs 0.0043）已含在总误差 (8) 内** ⇒ 是保守取值，不是内部矛盾

**残留问题（issue #7）**：论文**未给 `Arg Det M_q` 数值**。若格点取 Yukawa 相位为实，
则数值上 `θ̄ ≡ θ_QCD`，该斜率既可当 θ 系数也可当 θ̄ 系数用——**比值不受影响，但归因不可分**。

## 三、为什么流传的 `1.18×10⁻¹⁰` 是过时的

这个数来自 **2006 年实验 + 1999 年理论**，两个输入都已更新：

```
1.18e-10 = 2.9e-26 ÷ 2.46e-16      ← 反解出来才知道用的是 2.46
```

| 系数 | 回算上限 | 与 1.18e-10 的差 |
|---|---|---|
| **2.46e-16** | **1.1789e-10** | **0.09% ✅** |
| 2.4e-16（PR 1999 原值） | 1.2083e-10 | 2.3% ❌ |
| 2.5e-16（PR 2005 综述） | 1.1600e-10 | 1.7% ❌ |
| 1.2e-16（PR 2000 NNLO） | 2.4167e-10 | 105% ❌ |

**流传的 1.18 用的是 2.46，不是 PR 的原值 2.4。**

`2.46e-16` 的原始出处本仓库未核到，标【推断】——但 0.09% 的匹配度远优于其他候选，可作工作假设。

**教训不是"谁算错了"，是"流传的数字在传抄中换了系数的第三位有效数字"，
而那一位置恰好改变了结论的表述精度。**（见 issue #5）

## 四、当前最好的上限

```
实验（PSI 2020 原文）:  |d_n| < 1.8 ×10⁻²⁶ e·cm  (90% CL)
理论（格点 2026）:      d_n/θ̄ = 5.0×10⁻¹⁶ e·cm
⇒                     |θ̄|  < 3.60 ×10⁻¹¹
```

用 1.645σ 自推则为 `3.68×10⁻¹¹`。**两者并存。**

对照：标准模型无保护机制的预期是 `θ̄ ~ O(1)`。压缩倍数 ≈ **3×10¹⁰**。

## 五、六个候选方案：谁是解释，谁是改名

### 5.1 判据

> **它引入的那个额外输入，能不能被别的实验独立测出来？**
>
> - **能测** = 解释（有独立生死线，可被单独杀死）
> - **不能测** = 改名（把"为什么小"换成"为什么这个参数取这个值"，问题平移一步）

这条判据是本仓库在 2026-11-24 结 Q4 时确立的，细则见 `docs/method.md` 第五·补节。

**必须补一句**：综述里对"solution"的定义更严格——**必须解释参数为什么不存在或足够小，
而不是把 `|θ̄| ≲ 10⁻¹⁰` 当作未解释的输入**【实测 · arXiv:2609.00620 §6.1】。
本文的判据是它的**可操作化**：用一个能被实验检查的标准来判断"解释"是否只是空话。

### 5.2 对照表

| 方案 | 机制（做什么） | 额外输入 | 该输入可否独立测量 | 判定 |
|---|---|---|---|---|
| **① 无质量上夸克** | 让 `θ̄` 变得非物理（手征转动可吸收） | 无 | — | **已被格点排除**（m_u ≠ 0） |
| **② PQ 机制（轴子）** | `θ̄_eff = θ̄ + a(x)/f_a`，动力弛豫到 0 | 破缺能标 `f_a` | **能**—轴子质量/耦合（ADMX、CAST、HB 星） | **解释** |
| **③ Nelson–Barr** | UV 精确 CP + 自发破缺；质量矩阵det 在树阶为实 | 新粒子质量谱 | **能**—CKM CP 相位偏差（B 介子精确测量） | **解释** |
| **④ 宇称/左右对称** | 用 P 约束 θ 与质量矩阵结构 | 镜像扇区能标 | **部分能**—镜像粒子/右手中微子 | **解释（待测）** |
| **⑤ 高分立 θ 投影（Z_N）** | 规范 Z_N ⊂ 2π 平移，使 `|θ̄| ≤ π/N` | 整数 N（clockwork 层数） | **能**—格点 cusp 位置反解 N | **改名\\*** |
| **⑥ 高能 CP 完全守恒** | 假设 UV 完全守恒 + 破缺机制 | 一个新假设 | **部分**—须先说明破缺能标 | **改名** |

### 5.3 各方案的说明与已知问题

**① 无质量上夸克 — 已死**
需要 `m_u = 0`。格点已确定 `m_u ≠ 0`（Kaplan–Manohar 歧义已被格点解决）。
**排除的依据是数值，不是论证**——这是六条里唯一被干净杀掉的一条。

**② PQ / 轴子 — 主流，唯一有独立生死线**
`m_a = 5.691(51) μeV × (10¹² GeV / f_a)`【实测 · arXiv:2609.00620 式(9.8)】。
- `f_a` 越大，轴子越轻、耦合越弱
- 已有实验窗口：ADMX（few-μeV）、CAST（`g_aγγ < 5.8×10⁻¹¹ GeV⁻¹`, 95% CL, `m_a ≲ 0.02 eV`）
- **它的额外输入有一个可以被实验直接杀死的名字：`f_a`**

**但轴子有 quality problem**：量子引力预期不容忍精确全局对称，
Planck 压低的高维算子会给 `f_a` 引入修正，把 θ̄ 推回 O(1)。这是轴子方案的真实软肋。

**③ Nelson–Barr — 也有 quality problem**
UV 精确 CP，自发破缺，质量矩阵的 det 在树阶保持实。
**Nelson–Barr quality problem**：高维算子会使 `δθ̄ ~ c_S v_CP/Λ_UV`，
要求 `|δθ̄| ≲ 10⁻¹⁰` 给出 `v_CP ≲ 10⁸–10⁹ GeV`
【实测 · arXiv:2609.00620 §8.3，引 [138]】。
⇒ **它也需要额外结构来压制危险算子**（规范对称、分离 CP 破缺扇区、超对称等）。

**④ 宇称 / 左右对称** — 与 ③ 同类（UV 对称），但需要镜像扇区，能被 LHC / 中微子实验部分检验。

**⑤ θ 投影 Z_N — 机制对，但 N 自由**
- `|θ̄| ≤ π/N` 那一步是**鸽笼原理**（arXiv:2603.05195 式 3.6）：
  单位圆上 N 个等距点必有一个距原点 ≤ π/N。**纯几何，无物理输入，这一步赢不了。**
- 要满足 `3.60×10⁻¹¹` 需 **N ≳ 8.7×10¹⁰**
- **N 从哪来**：discrete clockwork 链的层数乘积，**层数无限制**
- **有没有引力约束**：目前没找到。而且论文自己论证离散规范对称是 QG **尊重**的
  （不同于会被破坏的全局对称）⇒ **不能反过来用 QG 卡 N**

**\\* 所以判"改名"，但不判死**：它有一个格点可测的特征——
θ 依赖**分段解析**、在约化周期的**奇分数倍处有 cusp**、全局曲率按 **1/N²** 标度。
**cusp 位置 = 2π/N 的奇分数倍，反解就能定 N。** 这不是空转，是"参数待格点定"。（见 issue #3）

**⑥ 高能 CP 完全守恒 — 改名**
不说破缺发生在哪个能标，就等于没有预言。**注意**：
一个没有独立预言的方案，**不因别的方案失败而变成对的**。

## 六、必须放进来的第六条路：这个问题本身可能不成立

**这是我认为任何诚实的 status 文档都必须写的一节，哪怕它与前五节方向相反。**

arXiv:2609.00620 的 Part IV 直接问：「Is there really a strong CP problem?」

它质疑的不是最后一步（θ̄ 依赖 → CP 破坏观测量，这步无争议），而是**前面几步**：

| 质疑 | 内容 | 原始文献（已核） |
|---|---|---|
| **Caveat 1：规范冗余** | 传统 θ-vacuum 构造假设"可容许规范变换在空间无穷远处趋于常数"，并把跨扇区激发的叠加当作物理态。**这个限制不在正则哈密顿形式里**；且跨扇区叠加在规范固定内积下不可归一化。放开来后，配合完全规范固定 + 哈密顿量厄米性，物理态空间受限到只剩一个 θ⁽ⁱ⁾（与 θ−θ_Π 相消）——**是「θ 被定死并相消」，不是「θ 不存在」** | Ai, Garbrecht, Tamarit, **arXiv:2403.00747**「The QCD theta-parameter in canonical quantization」**v1【读码】**（2026-11-25，见下）；⚠️ 同日核：辩护方 2510.18951 正文对本文零回应 |
| **Caveat 2：拓扑扇区与极限顺序** | Euclid 路径积分传统做法是**先对整数拓扑扇区求和（有限体积），再取无穷体积极限**。该工作主张反过来：**先取无穷体积极限（固定拓扑荷），再求和**。此时质量项与瞬子效应的手征相位**对齐**，无额外相位时不产生 CP 破坏 | Ai, Cruz, Garbrecht, Tamarit, **arXiv:2001.07152**（PLB 822, 136616）【实测·已核摘要】 |

**第二条的原摘要我读到了，逐字要点**：

> "we therefore take the infinite-volume limit before summing over topological sectors. In contrast to the opposite order of limits, **the chiral phases from the mass terms and from the instanton effects then are aligned** so that, in absence of additional phases, these do not give rise to [CP violation]"
